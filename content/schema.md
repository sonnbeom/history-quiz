# 인물 데이터 스키마 (schema.md)

- 대상 파일: `content/figures.json`
- 이 문서의 허용 값 목록이 기준이다. figures.json의 `era`, `state`, `roles`, `fields`는 아래 목록의 문자열과 **글자 그대로** 같아야 한다(띄어쓰기, 가운뎃점 포함).
- 값을 바꿔야 하면 figures.json 담당이 직접 고치지 않고 "변경 제안"에 적어 승인을 받는다.
- 값 목록은 `content/research/exam_figures.md` 3-1절(2회 이상 출제 인물 124명, 외국인 5명 포함)과 4-2절 시대 분포를 모두 표현할 수 있게 정했다.

## 1. 시대 (`era`) - 단일 값

인물 1명에 값 1개. 오답 시 시대 일치 여부를 비교한다.

| 값 | 범위 | 정의와 경계 |
|---|---|---|
| 선사 | ~고조선 성립 이전 | 구석기~청동기 초기. 이름이 전하는 인물이 거의 없어 현재 대상 인물은 없을 수 있으나 값은 유지한다. |
| 고조선 | 기원전 2333(건국 전승)~기원전 108 | 단군, 위만 조선, 우거왕 등. 경계: 기원전 108년 한 군현 설치(고조선 멸망). |
| 삼국 | 기원전 108~668 | 고구려·백제·신라·가야와, 고조선 멸망 후 삼국 이전의 여러 나라(부여, 옥저, 동예, 삼한)를 모두 포함한다. 끝 경계는 668년 고구려 멸망. |
| 남북국 | 668~935 | 신라(통일 후)와 발해, 그리고 후삼국(후백제·태봉) 소속 인물. 668년 이후 신라는 시대 값을 "남북국"으로 쓴다. 끝 경계는 935년 신라 멸망(936년 후삼국 통일). |
| 고려 | 918~1392 | 왕건의 고려 건국부터 조선 건국 전까지. 918년 이후에도 후백제·신라 소속이면 "남북국", 고려 소속이면 "고려". |
| 조선 전기 | 1392~1592 | 조선 건국부터 임진왜란 발발 전까지. |
| 조선 후기 | 1592~1863 | 임진왜란부터 흥선 대원군 집권 전까지. 임진왜란 중에 활약한 인물(이순신, 권율, 류성룡 등)은 조선 후기. 광해군·인조 이후 모두 후기. |
| 개항기 | 1863~1910 | 고종 즉위·흥선 대원군 집권(1863)부터 국권 피탈(1910.8)까지. 강화도 조약(1876)이 아니라 1863년을 시작으로 삼은 이유는 병인양요, 신미양요 등 개항 직전의 대원군 정권 인물을 별도 시대 없이 담기 위해서다. 대한제국기(1897~1910)를 포함한다. |
| 일제강점기 | 1910~1945 | 국권 피탈부터 광복(1945.8.15)까지. 3·1 운동, 임시정부, 독립군 활동 포함. |
| 현대 | 1945~ | 광복 이후 현재까지. 미군정, 대한민국 정부 수립, 6·25, 민주화, 남북 관계 포함. |

### 시대 배정 규칙
1. 한 인물에 시대 1개만 쓴다. **대표 업적(퀴즈에서 가장 많이 묻는 업적)이 속한 시대**를 고른다. 판단이 갈리면 `active_period` 중 더 긴 구간이 속한 시대를 쓴다.
2. 왕조 교체기 인물은 새 왕조 건국 업적이 대표면 새 시대로 쓴다. 이성계·정도전은 "조선 전기", 왕건은 "고려".
3. 후삼국 인물(견훤, 궁예)은 "남북국". 왕건과 고려 건국 후 그 휘하에서 활약한 인물(신숭겸, 유금필)은 "고려".
4. 668년 전후에 걸친 인물은 활동 기간 과반이 속한 쪽. 예: 김춘추(태종 무열왕)는 "삼국", 문무왕은 "남북국"(대표 업적이 나당 전쟁 승리와 통일 완성).
5. 일제강점기에 시작해 광복 후까지 활동한 인물은 대표 업적 기준. 김구·김규식·여운형은 "일제강점기", 이승만은 대한민국 정부 수립·집권이 대표이므로 "현대".
6. 외국인도 한국사에서 활동한 시기를 기준으로 같은 값을 쓴다.

## 2. 국가·왕조 (`state`) - 단일 값

인물이 **가장 대표적으로 활동한 국가**. 인물 1명에 값 1개.

| 값 | 정의와 경계 |
|---|---|
| 고조선 | 단군 조선, 위만 조선(기원전 108 멸망). |
| 부여 | 부여(기원전 2세기경~494). 옥저, 동예, 삼한 등 다른 초기 국가는 "기타". |
| 고구려 | 기원전 37(전승)~668. 고구려 부흥 운동(검모잠, 안승)도 고구려. |
| 백제 | 기원전 18(전승)~660. 백제 부흥 운동(흑치상지)도 백제. |
| 신라 | 기원전 57(전승)~935. **통일 전후를 하나로 합쳐 "신라"로 쓴다**(아래 결정 이유). |
| 가야 | 금관가야, 대가야 등 가야 연맹(~562). |
| 발해 | 698~926. |
| 후백제 | 900~936. 견훤. |
| 태봉 | 901~918. 궁예(후고구려). 인물 표기는 "태봉"으로 통일. |
| 고려 | 918~1392. |
| 조선 | 1392~1897. 개항기라도 1897년 대한제국 선포 전 활동이 대표면 "조선"(흥선 대원군, 김옥균, 김홍집, 박규수, 어재연, 양헌수). |
| 대한제국 | 1897~1910. 대한제국 선포 후 활동이 대표면 쓴다. 고종(광무개혁, 황제), 순종, 민영환, 의병장, 안중근, 이상설 등. 고종은 황제 즉위가 상징이므로 "대한제국"으로 정한다. |
| 대한민국 임시정부 | 1919~1945. 임시정부 요직(주석, 국무위원, 광복군 사령관 등)에서 활동하는 것이 대표인 인물(김구, 지청천, 조소앙, 김규식). |
| 해당 없음 | 1910~1945 국권 상실기에 독립운동·사회 활동을 했으나 임시정부 소속이 대표가 아닌 인물(박상진, 김원봉, 신채호, 방정환, 나운규 등). 일본 통치하라는 뜻이며 국가 값이 아님. |
| 대한민국 | 1948~. 정부 수립 후 활동이 대표인 인물(이승만, 박정희, 김대중 등). 1945~1948 미군정기 활동자(여운형, 장면 등)도 "대한민국"으로 쓴다(별도 값 만들지 않음). |
| 북한 | 1948~. 김정일 등. |
| 외국 | 중국, 일본, 영국, 독일, 미국 등 외국 인물 전부. 필요하면 별칭 설명은 `achievements`에 쓴다. |
| 기타 | 위에 맞는 값이 없을 때(부여를 제외한 옥저·동예·삼한 등). 가능하면 쓰지 않는다. |

### 통일신라를 신라에 합친 이유
- 통일 전후를 나누면 같은 왕조 인물이 두 값으로 갈려, 오답 비교 시 "같은 왕조"가 안 잡힌다(예: 진흥왕과 신문왕은 같은 신라).
- 시대 값이 이미 "삼국"과 "남북국"으로 통일 전후를 구분한다. 신라이면서 시대가 다르면 "왕조는 같고 시대는 다름"으로 부분 유사도가 나와 오히려 정보가 늘어난다.
- 후삼국 때문에 "후백제", "태봉"은 별도 값으로 둔다(왕건과 견훤·궁예가 헷갈리는 쌍이라 구분 필요).

### 국가 배정 규칙
- 상태 변화로 둘 이상에 걸치면 대표 활동 시점의 국가 하나.
- 고려 말~조선 초 인물은 대표 업적의 국가: 이성계·정도전 "조선", 최영·정몽주·이색 "고려".
- 1945~1948년 활동자와 건국 과정 인물은 "대한민국"(김구는 임시정부 대표 활동이므로 "대한민국 임시정부").

## 3. 신분·역할 (`roles`) - 복수 값(1~3개)

배열. 가장 대표적인 역할을 앞에 둔다. 비교는 배열 겹침으로 한다. 3개를 넘기지 않는다.

| 값 | 정의 |
|---|---|
| 국왕 | 왕, 황제, 대통령 이전 군주. 재위한 군주 전부(여왕 포함). |
| 왕족 | 국왕을 제외한 왕실 구성원: 왕비, 세자, 대군, 공주, 왕의 형제·종친. |
| 문신·관료 | 문관, 재상, 외척 관료, 지방관, 개화기 이전의 관료 일반. 유학자 출신 관료 포함. |
| 무신·장수 | 무관, 장군, 수군·의병 이전의 군사 지휘관, 무신 집권자(최우, 최충헌, 정중부). |
| 학자·사상가 | 학문·사상·역사서 저술, 과학기술자 포함(유학자, 실학자, 역사가, 의관, 과학자). 관직 겸임이면 `roles`에 같이 둔다. |
| 종교인 | 승려, 천주교·동학·대종교 등 종교 지도자와 교인. |
| 예술가·문인 | 화가, 서예가, 음악가, 문학가, 영화인, 건축가 등. |
| 개혁가·혁명가 | 갑신정변·개화파, 농민 봉기·반란·혁명을 이끈 사람(전봉준, 김옥균, 묘청 등), 개혁 정책 주도자(조광조). |
| 독립운동가 | 1895 을미의병 이후 항일 의병, 애국계몽, 무장 투쟁, 의열 투쟁, 임시정부, 광복군 활동가. 1895년 이전 외세 저항은 해당 역할(무신·장수 등)을 쓴다. |
| 사회운동가 | 노동·농민·여성·소년·학생·언론·민주화 운동, 교육·계몽, 경제 자립 운동(방정환, 이상재, 박종철, 이한열, 조만식). |
| 정치인 | 1945년 이후와 일제강점기 정당·정치 단체 활동 중심 인물(대통령, 총리, 국회의원, 정당 지도자, 좌우 합작 지도자). |
| 기타 | 위에 맞지 않는 경우(상인, 외국인 선교사·외교관·언론인 등). 가능하면 쓰지 않는다. |

### 역할 규칙
- 외국인은 하는 일 기준으로 역할을 고르고 `state`를 "외국"으로 둔다.
- 외척이면서 문신이면 "문신·관료"만(이자겸, 민겸호).
- 독립운동가이면서 정치인이면 대표 순서로 둘 다(김구: 독립운동가, 정치인).
- 의병장은 시기에 맞춰 1895 이후면 "독립운동가", 임진왜란 의병은 "무신·장수".

## 4. 활동 분야 (`fields`) - 복수 값(1~3개)

배열. 대표 분야를 앞에 둔다. 비교는 배열 겹침으로 한다.

| 값 | 정의 |
|---|---|
| 정치 | 왕권 강화, 개혁, 정변, 집권, 정당·정부 운영, 제도·법 정비. |
| 외교 | 대외 교섭, 사신, 조약, 외교 문서, 외교 정책. |
| 군사 | 전쟁, 전투, 정벌, 군제 개편, 의병·군대 활동. |
| 경제 | 토지·조세·화폐·상업·산업 정책과 경제 운동(대동법, 직전법, 경제 개발 계획). |
| 사상·종교 | 불교, 유학(성리학) 이념, 천주교, 동학, 대종교 등 사상과 종교 활동. |
| 학문 | 역사서·문집 저술, 연구, 교육, 어문 연구(한글, 국어). |
| 문화·예술 | 그림, 글씨, 음악, 문학, 영화, 건축, 인쇄, 풍속. |
| 과학기술 | 천문, 의학, 화약, 농업기술, 금속활자 등. |
| 사회운동 | 노동·농민·여성·소년·학생 운동, 계몽·교육 운동, 민주화 운동, 언론. |
| 독립운동 | 항일 의병, 무장 투쟁, 의열 투쟁, 임시정부, 외교 독립론, 애국계몽. |

### 분야 규칙
- 인물 분야는 3개를 넘기지 않는다. 가장 대표적인 것 위주.
- "독립운동"은 1895년 이후 항일 활동에만 쓴다.
- 6월 민주 항쟁처럼 민주화 운동은 "사회운동"(정치 개혁이 핵심이면 "정치"를 함께).

## 5. 활동 시기 (`active_period`)

```json
"active_period": { "start": 1418, "end": 1450 }
```

- 정수 연도(서기 기준). **생몰년이 아니라 대표 활동 기간**이다.
  - 국왕: 재위 기간(즉위 연도~퇴위·사망 연도). 세종 1418~1450.
  - 예외(2026-11-26 추가): 즉위 전 활동이 대표 업적에 들어가는 건국자는 그 활동 시작 연도부터 퇴위까지 잡는다(예: 이성계, 왕건). 근거 연도를 achievements에 적는다.
  - 관료·장수·학자: 대표 활동이 시작된 해부터 끝난 해까지(과거 급제, 주요 사건 참여 등).
  - 단일 사건이면 `start`와 `end`를 같게 쓴다(예: 안중근 하얼빈 의거 1909~1909).
- **기원전은 음수**. 기원전 108년 → `-108`. 연도 0은 없다(기원전 1년 = `-1`, 서기 1년 = `1`).
- **미상은 null**. 시작만 알면 `end`만 null, 둘 다 모르면 둘 다 null. 어림짐작으로 채우지 않는다.
- **추정치 표기**: 연도가 전승·추정이면 `active_period`에 `"approx": true`를 붙인다(예: 단군 `{ "start": -2333, "end": null, "approx": true }`). 추정이 아니면 `approx`는 생략한다. 여러 학설이 있으면 백과사전 기준을 따르고 `achievements`나 보고에 적는다.
- `start`는 `end`보다 크지 않다.
- 시대 경계와 맞지 않아도 된다(`era`는 대표 업적 기준이고 활동 시기는 연도 비교용).

## 6. figures.json 필드 정의

파일은 인물 객체의 JSON 배열이다(UTF-8, 들여쓰기 2칸).

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `id` | string | 필수 | 고유 식별자. 아래 id 규칙. 파일 안에서 중복 금지. |
| `name` | string | 필수 | 표준 표기(학교 교과서 기준). 정답 표기. 예: "세종대왕", "이순신". |
| `aliases` | string[] | 필수 | 학생이 입력할 법한 다른 이름(묘호, 본명, 호, 시호, 흔한 호칭, 줄임말). `name`과 같은 문자열은 넣지 않는다. 다른 인물과 겹치는 별칭은 넣지 않는다(예: "태조", "숙종", "성종", "무왕"만으로는 쓰지 않음). 없으면 빈 배열. |
| `era` | string | 필수 | 1절 값 하나. |
| `state` | string | 필수 | 2절 값 하나. |
| `roles` | string[] | 필수 | 3절 값 1~3개. |
| `fields` | string[] | 필수 | 4절 값 1~3개. |
| `active_period` | object | 필수 | 5절. `start`, `end`는 정수 또는 null. `approx`는 선택(true만). |
| `achievements` | string[] | 필수 | 대표 업적 서술 2~5개. 짧은 완결 문장. 기출 지문을 베끼지 않고 새로 쓴다. |
| `related_events` | string[] | 필수 | 관련 사건·제도·저술 이름(예: "위화도 회군", "경국대전"). 없으면 빈 배열. |
| `exam_count` | integer | 필수 | `content/research/exam_figures.md`의 출제 횟수 그대로. 이름 통합(예: 거련=장수왕)은 그 문서 기준을 따른다. |
| `sources` | object[] | 필수 | `{ "title": string, "url": string }`. 실제로 확인한 URL만(한국민족문화대백과사전, 우리역사넷 등). 확인 못 한 URL은 쓰지 않고 빈 배열도 허용하되 보고에 적는다. |
| `confusable_ids` | string[] | 필수 | 혼동하기 쉬운 인물 id. 비슷한 시기의 왕, 같은 사건 인물, 업적이 비슷한 인물. 자기 id 금지. 가능하면 양방향. 없으면 빈 배열. |

### id 규칙
- **영문 소문자 + 숫자 + 하이픈**만 쓴다(`^[a-z0-9]+(-[a-z0-9]+)*$`).
- 표기는 국어의 로마자 표기법(2000) 기준. 성씨 "이"는 `yi`로 쓴다(예시 `yi-sun-sin`에 맞춤). 그 밖의 성씨는 표기법대로(`gim`, `bak`, `choe`, `jeong`).
- 이름은 음절마다 하이픈으로 끊는다: 이순신 `yi-sun-sin`, 김옥균 `gim-ok-gyun`, 박정희 `bak-jeong-hui`.
- 국왕은 묘호(또는 왕호)의 로마자 한 단어: `sejong`, `yeongjo`, `jeongjo`, `gwanggaeto`, `jangsu`.
- 같은 로마자가 둘 이상 생길 수 있는 묘호(태조, 태종, 성종, 숙종, 현종, 예종, 원종, 고종, 무왕, 성왕, 문왕 등. 고종은 2026-11-26 추가: 고려 고종과 충돌)는 앞에 국가 영문을 붙인다: `joseon-sukjong`, `goryeo-sukjong`, `joseon-seongjong`, `goryeo-seongjong`, `baekje-seong`, `balhae-mu`. 같은 묘호가 DB에 하나뿐이어도 이 목록에 있는 묘호는 접두를 쓴다.
- 이성계와 왕건은 이름 형태로: `yi-seong-gye`, `wang-geon`. 김춘추는 `gim-chun-chu`, 대조영은 `dae-jo-yeong`.
- 왕이 아닌 한 사람이 둘 이상 이름으로 알려져도 id는 `name`의 로마자 하나만 쓴다(별칭은 `aliases`).
- 동명이인: 역할이나 시대 단어를 뒤에 붙인다(`gim-gyu-sik`과 독립군 김규식은 `gim-gyu-sik-army` 등). 2회 이상 출제 인물 중 동명이인은 김규식(정치가·독립군) 정도이며 독립군 김규식은 1회 출제라 당분간 만들지 않는다.
- 국가 접두 영문: `gojoseon`, `buyeo`, `goguryeo`, `baekje`, `silla`, `gaya`, `balhae`, `goryeo`, `joseon`.
- 한 번 정한 id는 바꾸지 않는다(다른 파일이 id를 참조한다).

### 검증 규칙(스크립트)
- JSON 문법, 필수 필드 전부 존재, 타입 일치.
- `era`, `state`, `roles`, `fields` 값이 이 문서 목록 안에 있음. `roles`·`fields`는 1~3개, 중복 없음.
- `active_period.start <= end`(둘 다 null 아닐 때), 정수 또는 null, 연도 0 금지.
- id 정규식과 중복 검사. `confusable_ids`에 자기 id 없음, 미등록 id는 보고에 따로 적음.
- `aliases` 안의 문자열이 다른 인물의 `name`이나 `aliases`와 겹치지 않음.

## 7. hints.json 참조

- 형식(hint-writer 정의를 따름): `{ "<figure id>": [ {"level": 1, "text": "...", "sources": [{"title": "...", "url": "..."}]}, ... level 5까지 ] }` (sources는 1개 이상. 2026-11-26 단일 source에서 배열로 변경). 인물마다 정확히 5개, level 1이 가장 어렵고 5가 가장 쉽다.
- 이 문서가 정하는 것은 연결 규칙뿐이다: hints.json은 인물을 **figures.json의 `id`**로 가리킨다. 존재하지 않는 id를 참조하면 안 되고, figures.json 인물마다 힌트가 있는지는 hints 담당이 검사한다.
- 힌트에는 인물 이름(`name`, `aliases`)을 그대로 쓰지 않는다(정답 노출 방지).

## 8. 값 크기 점검(유사도 비교용)

2회 이상 출제 한국인 119명 기준 예상 분포(대략). 시대 값은 아래 숫자에서 크게 벗어나지 않게 한다.

| 시대 | 예상 인원 | 비고 |
|---|---|---|
| 선사 | 0 | 값만 유지 |
| 고조선 | 1(우거왕) | 매우 적음. 변경 제안 1 참고 |
| 삼국 | 약 11 | 광개토·장수·고국원·개로·무령·성(백제)·문주·지증·진흥·김춘추 등 |
| 남북국 | 약 12 | 신문왕·문무왕·혜공왕·원성왕·진성여왕·김지정·장보고·최치원·대조영·발해 무왕·견훤·궁예 |
| 고려 | 약 30 | 가장 많음. 하위 구분 없음(무신 정권은 `roles`, `related_events`로 구분) |
| 조선 전기 | 약 10 | 이성계·정도전·태종·세종·세조·성종·성현·조광조·연산군 등 |
| 조선 후기 | 약 12 | 영조·정조·숙종·송시열·이원익·광해군·정선·박제가·채제공·권율·신립·김정희 등 |
| 개항기 | 약 19 | 고종·흥선 대원군·김옥균·민영환·최익현·안중근 등 |

- 국가 값은 신라(약 12), 고려(약 30), 조선(약 25)이 크고, 후백제·태봉·부여는 1~2명이다. 인원이 매우 적은 값은 변경 제안에 적었다.
- 사회운동가, 개혁가·혁명가, 종교인은 역할 수가 적은 편이므로 `fields`와 함께 쓰이도록 한다.

## 변경 제안

기본안은 위 목록 그대로 둔다. 아래는 승인이 필요한 제안이다.

1. **"선사"와 "고조선"을 "선사·고조선" 하나로 합치기.** 선사는 인물이 0명, 고조선은 2회 이상 출제가 우거왕 1명뿐이다. 합치면 단군, 위만, 우거왕, 준왕 등이 "같은 시대"로 묶인다. 기본안은 사용자 예시를 따라 분리해 둔다.
2. **"남북국"을 "남북국·후삼국"으로 이름 바꾸기, 또는 "후삼국"을 별도 시대로 두기.** 견훤·궁예 2명만 따로 두면 시대 값이 너무 작아져서 기본안은 남북국에 포함했다. 대신 시대 이름만 바꿔 학생이 헷갈리지 않게 하는 방안.
3. **"개항기"를 "근대"로 이름 바꾸기.** 시작을 1863년으로 잡았으므로 "개항기"라는 이름과 맞지 않는다. 이름만 바꾸는 제안이며 범위는 그대로.
4. **"해당 없음" 국가 값 이름.** 일제강점기 인물 상당수가 이 값을 쓰게 되고 임시정부 소속 여부도 판단이 갈린다(김원봉은 광복군 부사령관·임시정부 군무부장이지만 의열단·조선의용대 활동이 대표). 대안은 "일제강점기 독립운동 단체" 같은 이름이나, 임시정부 값을 더 넓게 쓰는 것.
5. **"부여"와 "기타" 국가.** 부여는 인물이 거의 없어 값이 작다. 필요하면 삼한·옥저·동예와 함께 "초기 국가"로 합치는 제안.
6. **국가 "신라"와 "통일신라" 분리.** 기본안은 합쳤다. 분리하면 국가 비교가 시대 비교와 겹쳐 정보가 중복된다는 점이 이유다.
7. **"고려" 시대 세분(전기·무신 집권기·원 간섭기).** 고려가 약 30명으로 가장 크다. 세분하면 비교가 정교해지나 값이 늘고 경계 판정이 많아져 기본안은 세분하지 않았다.
