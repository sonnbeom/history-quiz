# 콘텐츠 검수 기록 (review.md)

- 검수자: 독립 검수(fact-checker). figures.json, hints.json, schema.md는 읽기만 한다.
- 대조 출처: 한국민족문화대백과사전(encykorea.aks.ac.kr) 등을 WebFetch로 직접 열어 확인. "열람"은 본문을 열어 해당 문장을 확인한 것, "검색만"은 검색 결과 요약으로만 본 것.
- **지난 기록:** 1~4단계 검수 기록(119명 전원 통과, 2026-11-26~28)은 `content/review_archive.md`로 옮겼다. 통째로 읽지 말고 필요한 id나 지적 번호만 Grep으로 찾는다.
- figures.json·hints.json에 이미 들어간 url은 검수에서 열람 확인된 것이다.
