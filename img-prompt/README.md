# 인물 도트 이미지 작업

인물 119명의 도트 이미지를 외부 이미지 생성 AI(ChatGPT·Gemini 등)로 만든다. Claude는 `[인물]` 칸을 채우고 결과물을 검수한다.

## 파일
- `portrait_template.md`: 최종 공통 프롬프트. `[공통 규격]`은 바꾸지 않는다.
- `batchN.md`: 묶음별로 `[인물]` 칸을 채운 목록(10명씩).
- 기준 이미지: `ref-image/ref-character/yisunsin_dot_64.png` (이순신. 화풍 기준이며 수록 인물은 아님)
- 생성한 이미지는 모두 커밋·push한다(2026-11-28 사용자 결정). 단 남의 저작물(ex-character.png, ref-screen 스크린샷)은 공개 저장소라 올리지 않는다

## 확정된 화풍 (2026-11-28)
- 64x64 도트, 1.5등신 SD, 정면, 투명 배경, 위아래 여백 2px, 몸 중심 가로 가운데
- 기준 이미지 팔레트 18색: 외곽선 #2A2430, 피부 #F2C9A0 / #DEAA82, 코 #B87C5A, 볼 #F09682
- 결과물은 64px 원본과 512px(8배 nearest)을 같이 받는다. 앱에는 64px을 쓰고 CSS로 확대한다(`image-rendering: pixelated`)
- 파일명은 `{figures.json id}.png`. 검수를 통과하면 64px은 `assets/portraits/{id}.png`, 512px은 `assets/portraits/512/{id}.png`로 옮겨서 커밋한다
- 규격 검사: `node tools/check_portrait.js 파일.png ...` (크기, 투명, 반투명, 색 수, 위아래 여백, 8배 격자)
- 제작 순서: `primary.md`의 1차 35명(기출 4회 이상)을 먼저 한다

## `[인물]` 칸 채우는 규칙 (Claude용)
- 4줄을 채운다: 인물(시대와 한 줄 정체), 복장, 소품, 표정/특징.
- 얼굴 기록이 없는 인물이 대부분이므로 **복장과 소품으로 구별**한다. 시대·국가·신분에 맞는 복식을 쓴다(시대착오 금지).
  - 예: 조선 국왕은 붉은 곤룡포와 익선관, 고려 왕은 황포와 복두, 고구려는 조우관과 찰갑, 신라 왕족은 금관, 승려는 삭발과 장삼·가사, 선비는 도포와 갓, 개항기 이후 인물은 양복이나 두루마기.
- 소품은 대표 업적에서 1~2개 고른다. 업적은 `node tools/extract.js id`로 확인한다.
- 사진이 있는 근현대 인물은 특징(안경, 수염, 체구)만 글로 적는다. 사진, 표준영정, 동상 이미지는 첨부하거나 따라 그리게 하지 않는다(저작권).
- 같은 시대·역할 인물끼리는 색이나 소품을 달리해 서로 구별되게 한다(예: 권율 갑옷은 붉은색, 이순신은 남색).
- 현대 정치인도 같은 중립적 화풍을 쓴다. 희화화하지 않는다.
- 묶음은 10명씩 진행하고, 종류(국왕·장수·승려·여성·선비·근대 인물)를 섞는다.

## 결과물 검수 (Claude)
- 규격: 64x64, RGBA, 반투명 픽셀 없음, 위아래 여백 2px, 몸 중심 가로 가운데, 색 24개 이내, 512px 파일은 8배 격자 일치.
- 복장 고증, 기준 이미지와 화풍이 같은지.
