첨부한 이순신 도트 캐릭터와 같은 시리즈로 새 인물을 그려줘.
화풍, 비율, 얼굴 그리는 방식은 첨부 이미지와 똑같이 맞추고, 인물의 옷과 소품만 새로 디자인해줘.

[공통 규격]
- 64x64 픽셀아트, 정면, 1.5등신 SD (머리가 크고 몸이 짧게), 전신
- 부위마다 1px 진한 외곽선(#2A2430), 명암 2~3단계, 색 24개 이내
- 얼굴: 첨부 캐릭터와 같은 크기와 위치, 2x3 픽셀 점 눈 + 오른쪽 위 흰 하이라이트 1px,
  3px 분홍 볼터치(#F09682), 피부 #F2C9A0 / 그림자 #DEAA82 / 코 #B87C5A
- 배경 투명 PNG, 글자 없음
- 위아래 여백 2px (머리 꼭대기와 발끝이 캔버스 끝에 닿지 않게)
- 몸 중심을 캔버스 가로 가운데에 맞추기 (소품이 삐져나와도 몸 기준)
- 결과물: 64x64 원본 + 8배 확대(nearest-neighbor) 512x512, 두 파일
- 바닥 그림자, 테두리, 배경 장식 없음. 첨부 이미지를 수정하지 말고 새 이미지로 그려줘
